# Task 1 React Dashboard Development

Northstar is a responsive SaaS analytics dashboard built with React and Vite. It includes a responsive sidebar, navigation, KPI cards, revenue chart, recent orders table, user profile, notifications, search, animations, and mobile layouts.

## Run

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Deploy the generated `dist` directory to Vercel, Netlify, or another static host.
